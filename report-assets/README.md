# TrustLens AI — Report Visual Assets Directory

This directory contains all visual figures, architectural diagrams, empirical interface screenshots, and institutional logos that appear in the official 70-page academic report: **"TrustLens AI – Intelligent Document Verification, Fraud Detection, and Risk Analysis Platform"** (Chandigarh University, Master of Computer Applications).

All assets are maintained in high-resolution PNG format (300 DPI publication quality) with standard academic filenames.

## 3. Reproduction & Automated Rebuilding

All architectural diagrams in `diagrams/` are programmatically generated and fully reproducible using the provided generation script:

```bash
python scripts/generate_modern_styled_diagrams.py
```

This script utilizes `matplotlib` and custom vector rendering pipelines to enforce:
- Uniform color palette: Midnight Navy (`#0A192F`), Deep Teal (`#0D9488`), Electric Cyan (`#06B6D4`), Amber Warning (`#F59E0B`), and Emerald Safe (`#10B981`).
- Clean rounded card styling with explicit cardinality and process indicators.
- 300 DPI publication export dimensions suited for Word (.docx) and PDF printing.
